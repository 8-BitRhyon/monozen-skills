# Marketing Pipeline

> Position first, prove second, launch third, grow weekly. Copy serves the position, not the reverse.

## Stages

```
MARKETING.md
    |
    v
positioning  ->  POSITIONING.md
    |
    v
proof: demo, benchmark, quickstart, case study
    |
    v
gtm-loop  ->  LAUNCH.md  ->  GROWTH.md
    |
    v
marketing-copy  ->  COPY.md
```

1. **Context.** Fill [MARKETING.md](templates/MARKETING.md): buyer, category, enemy, proof, voice.
2. **Position.** Run [positioning](../skills/positioning/SKILL.md) and write [POSITIONING.md](templates/POSITIONING.md).
3. **Prove.** Ship the demo, benchmark, quickstart, and one named case study before buying traffic.
4. **Launch.** Run [gtm-loop](../skills/gtm-loop/SKILL.md) and write [LAUNCH.md](templates/LAUNCH.md).
5. **Grow.** Run the weekly loop in [GROWTH.md](templates/GROWTH.md). One experiment in flight.
6. **Write.** Run [marketing-copy](../skills/marketing-copy/SKILL.md) and write [COPY.md](templates/COPY.md).

## Commands

- `/market` runs the full pipeline.
- `/position` writes or revises the positioning contract.
- `/launch` builds the six-week launch.
- `/growth` runs the weekly growth loop.
- `/copy` drafts or edits an asset with a claim ledger.

## Cadence

- Positioning review: quarterly, or before a category or pricing change.
- Launch spike: one per week, maximum.
- Growth experiment: one in flight, pre-committed decision rule.
- Weekly metrics: time to first success, activation, week-4 retention, free to paid, net revenue retention.
- Monthly: one case study, one comparison page, one community thread, one partner conversation.

## What To Skip

- Paid search and display before activation works.
- Programmatic SEO and AI content at scale.
- App store optimization for a developer tool.
- Cold email at volume.
- Gated ebooks and webinars.
- Product Hunt as a pipeline. It is a badge.
- A DevRel hire before the quickstart works.

## Evidence

The pipeline is based on positioning research (Dunford, Moesta), developer GTM data (Stack Overflow, Octoverse), growth benchmarks (Lenny, RevenueCat), launch data (Show HN, Product Hunt), and the current marketing-skill ecosystem. Each skill carries its own source list.
