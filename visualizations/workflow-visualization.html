LAYER 2 - WORKSPACE ISOLATION

Pooled Git Worktrees

treehouse manages a reusable pool of isolated worktrees under ~/.treehouse/. Dependencies and build cache survive between tasks; leases prevent collisions.

LAYER 3 - TOOLING

Agent-ergonomic CLIs with TOON output instead of MCP schema overhead: ~79k tokens/task vs ~185k. No GUI required, terminal-native by design.

Security Posture

Secrets gitleaks full-history scan in CI; universal guard blocks IDs/secrets/fingerprints at commit/deploy
Supply chain All GitHub Actions SHA-pinned (zgosalvez ensure-sha-pinned check)
Machine hygiene Zero /Users/ paths or file:// refs in committed artifacts; em dashes banned repo-wide
Plugins Only install herdr plugins listed in scripts/setup.sh; audit diffs before enabling

Why This Is Seamless

Bootstrap -> Implement

new-project ships constitution + CI before the first feature, so test-driven-dev and the pre-commit gate work from commit one. No retrofitting.

Review -> Merge

code-review tags findings blocker/should/nit; pr-workflow polls required checks and merges only green. Protected main makes PRs mandatory.

Isolation -> Parallelism

treehouse gives each crewmate a pooled worktree with deps intact; herdr supervises states; firstmate reconciles results into one PR stream.

CLI -> Token Economy

AXI wrappers (TOON, totals, empty states, exit codes) keep every tool call lean: ~79k tokens/task vs ~185k for MCP schema overhead.
