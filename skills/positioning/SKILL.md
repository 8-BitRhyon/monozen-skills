# Positioning

> A position is a choice, not a slogan. It names the buyer, the alternative, the proof, and the category you want to be compared in.

## Contract

- Input: product, audience, 8-12 recent switchers or lost deals, product proof.
- Output: `POSITIONING.md` plus `MARKETING.md`.
- Stop: five best-fit prospects can restate the value and category without prompting.

## 1. Reconstruct The Switch

Interview recent switchers, lost deals, and churned users. Rebuild the timeline: first thought, passive look, active look, decision, first use. Record push, pull, anxiety, and habit. The struggling moment is the sentence you reuse.

## 2. List Real Alternatives

3-6, starting with "do nothing", a spreadsheet, an intern, or the existing platform. Mark which appeared on a real shortlist. Drop phantom competitors.

## 3. Attributes With Proof

3-5 attributes, each with an artifact: a reproducible benchmark, public repo, latency table, security report, or price. No artifact means it is a claim, not an attribute.

## 4. Value And Who Cares

Turn each attribute into an outcome. Write 2-3 value themes. Define the best-fit profile: trigger events, stack, team size, compliance regime. Write the anti-customer explicitly.

## 5. Category And Enemy

Default to an existing category or subsegment. Create a new category only when all four hold: no budget line exists, the nearest category triggers false assumptions, you can fund 2-3 years of education, and you have new vocabulary, proof, and a launch moment.

Pick one enemy: a practice or the status quo, never a weaker vendor. The buyer must already resent it in their own words, and one demo must falsify it.

## 6. Encode And Test

Write `POSITIONING.md` and `MARKETING.md`. Draft a one-liner, a five-slide narrative, and a homepage hero. Test with five best-fit prospects and three sales reps. Kill criteria: they restate you as the old category, or cannot repeat the value after one read.

## Proof Ladder

1. Reproducible benchmark: script, versions, hardware, p50/p95/p99.
2. Public demo with first value under 10 minutes.
3. Named case study with one metric and a time window.
4. Security and data handling: SOC 2, retention, subprocessors, DPA.
5. Cost: unit price, egress, idle cost, exit cost.
6. Local-first: offline test, open export, self-host path.

## Anti-Patterns

- Feature lists without value mapping.
- "AI-powered" as the claim. It now signals risk.
- Category confusion that triggers wrong assumptions.
- Two enemies, or a vendor as the enemy.
- Claims without an artifact.
