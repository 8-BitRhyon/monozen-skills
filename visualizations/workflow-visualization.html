Parallel TUI Agents

LAYER 3 — LIFECYCLE HOOKS

Agent State Awareness

Every agent reports its lifecycle: session start, pre/post tool use, blocked, working, idle, done. Native macOS toasts on blocked/done with click-to-focus. Session persistence via resurrect. Workspace isolation prevents file collisions.

freebuff.watcher cmd-hooks focus-notify resurrect worktrunk triage (attention ranking) attention (jump-to-agent)

Why This Is Seamless

Isolation → Launch

worktrunk creates a separate git branch per agent pane. Aider edits `src/auth.js` on branch `feature/auth`; Crush edits the same file on `feature/login` without collision. workspace-manager applies `.env` and `mise` setup automatically.

Lifecycle → Awareness

freebuff and commandcode plugins report blocked/working/done to herdr's socket API. focus-notify fires a native macOS toast when any agent finishes or needs approval. You click the toast and the terminal jumps to the exact pane.

Persistence → Continuity

resurrect saves workspace, tab, pane, cwd, and running agent state. Restart herdr or the machine: the multi-agent layout (freebuff pane + reviewr sidebar + file-viewer) restores exactly. No manual re-setup.

Context → Speed

Every agent pane has native access to fd (fast file find), rg (content grep), yazi (file manager with preview), bat (syntax highlight), and zoxide (directory jump). No context-switching out of the terminal.
